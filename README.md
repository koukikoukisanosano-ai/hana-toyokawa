# ベガビック1130豊川店 ハナハナ予想（クラウド版・iPhoneで見るだけ）

豊川市・ベガビック1130豊川店 の **ハナハナシリーズ** だけを対象に、過去の台データと店の癖から
「今日、出率（差枚）が高くなりそうな台」をランキングにし、打っている途中の「続けるか・移るか・やめるか」も判断します。
PCもiPhoneの操作も不要です。データの取得・学習・ページの作成と公開は、すべて GitHub（Actions）が自動で行います（無料）。

## 見方

予想ページ: `https://koukikoukisanosano-ai.github.io/hana-toyokawa/`

アナスロ・みんレポでは旧店名「ベガス豊川店」で掲載されています。
Safari で開いて「共有」→「ホーム画面に追加」すると、アプリのように開けます。

ページの内容
- **今日の店の強さ** … 日の種類（混む日・旧イベ日・火曜・平日）ごとの出率と、今後1週間の見込み
- **台別ランキング** … 今日の出率が高そうな順。各台に「過去に同じ順位だった台が実際どれだけ出たか」を表示。座るなら予想上位3台の空いている台
- **続けるか・移るか・やめるか** … 打っている台の機種・予想順位・G数・BIG・REG を入れると、この先の見込み出率と判定（続ける／空いている台に移る／やめる）を表示。早見表と、基準に従ったときの得の計算つき
- **島マップ** … 台の並びに色分け（◎上位10%・○上位30%・△中位・×下位30%）
- **予想の答え合わせ** … 毎日出した予想を、後から公開された実データで採点した結果
- **この店の癖** … 凹み台の戻り方・機種ごとの出率の推移（毎回計算し直し）
- **2年間の答え合わせ** … 過去の各日を、その日より前のデータだけで予想し直した成績（やり方別・月別・順位別）
- **予想方法の比較** … 2026/10/22 に行った方法の総当たり比較の記録

## 自動で動くタイミング（日本時間）

| いつ | 内容 |
|---|---|
| 毎朝 7:46 ごろ | 今日の予想ページを作成 |
| 30分ごと（毎時 7分・37分ごろ） | みんレポから未取得の日を取得して予想を更新 |
| プログラムや `config.yaml` を変えたとき | 取得を待たずにページだけすぐ作り直す |
| 週1回（自動） | 2年分の答え合わせ・この店の設定配分・撤退の基準を計算し直す |

## iPhoneからの操作

- **今すぐ実行したい**: GitHub の `hana-toyokawa` →「Actions」→「ハナハナ予想（豊川）」→「Run workflow」
- **設定を変えたい**: `config.yaml` を開いて鉛筆マーク（編集）→ 変更して「Commit changes」。次回の実行から反映
  - `islands` … 島の区切り（角台の判定用）。例 `islands: [[101, 110], [111, 120]]`
  - `event_digits` … 旧イベント日の日付末尾（いまは 0 と 5）
  - `closed_days` … 休業日（データが無い日は自動でも判定します）
- **動いているか確認**: 「Actions」に緑のチェックが並んでいればOK。赤い×は失敗（ページ上部にも注意が出ます）

## データの取得元

- **みんレポ** … GitHubが本物のブラウザ（Chromium）で開いて取得。全台の G数・BIG・REG（店名は旧名「ベガス豊川店」）
- 前日分がまだ載っていない時間帯は、載った時点で次の取得のときに取り込みます
- データは `data/` フォルダにCSVで保存されます（ハナハナの台のみ）

## しくみ

1. 差枚と出率は、BIG・REG回数とG数から機種ごとの獲得枚数とコイン持ちで計算（みんレポはこの店の差枚を伏せているため）。
   1Gあたりの消費は、この店の設定配分（`data/setting_prior.json`）とその台のBIG・REG回数から見込んだ設定で重み付け
2. 台選び: 機械学習（勾配ブースティング木、`hana/sysmodel.py`）が、直近の差枚・前日の結果・機種・日の種類などから
   「今日その台の出率が全台平均よりどれだけ高そうか」を予想。毎回、その日より前の全データで学び直す
3. 日選び: 日の種類ごとの出率（`hana/daystrength.py`）
4. 答え合わせ: 週1回、過去の各日をその日より前のデータだけで予想し直して成績を計算（`data/system.json`）
5. 撤退の判断（`hana/quitrule.py`）: 打つ前の見込み（予想順位ごとの過去の実績・今日の日の強さ・この店の設定配分）を、
   途中のG数・BIG・REG回数で更新して「この先の見込み出率」を出す。100%未満ならやめる、空いている台の方が0.4%以上高ければ移る。
   他の人のやめ方（負けたら早くやめる等）の偏りはこの計算に影響しない。効果の確認は `data/quit_research.json`

方法は 2026/10/22 に 2年分（621日）のデータで総当たりに比べて決めました（`data/research.json`）。
開発期間（2025/3〜2026/2）で方法を作って選び、選ぶのに使っていない本番テスト期間（2026/3〜10）で成績を確かめています。
`config.yaml` の `predict.method` を `system` 以外にすると、以前の方法に戻ります。

予想は公開データから計算した確率で、結果を保証するものではありません。遊技は余裕のある範囲で。
